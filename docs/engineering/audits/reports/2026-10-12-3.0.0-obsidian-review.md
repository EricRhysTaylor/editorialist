# Editorialist 3.0.0 Obsidian review follow-up

The live public Obsidian scorecard recognized 3.0.0 at
`82ad2e90e48b35100f02a03200d73cfd7f671520`, rated the review Satisfactory,
and reported 16 findings. Its build log confirmed that the production build
failed when attempting to copy artifacts into Mac-specific vault folders.

## Corrections for 3.0.1

- Make `npm run build` portable: full checks and a production bundle, without
  local vault writes. `npm run build:dev` explicitly builds and copies to the
  configured vaults. The copy command retains its missing-vault failure rather
  than silently skipping delivery. Backup retains explicit local delivery.
  The Linux quality workflow now also runs the public build command.
- Declare ES2022 libraries explicitly for existing `Array.at` calls. The review
  scanner lacks ambient Node type declarations that had masked those errors
  locally, causing unsafe-assignment/call/argument findings in AutoScheduleModal.
  Add `typecheck:scanner` without ambient Node types and use that same project
  for official report lint. Enable the four corresponding typed unsafe rules.
- Replace three `:has` selectors with explicit checkbox/textarea wrapper classes
  created by the existing field helpers. Layout behavior remains the same.
- Replace the flagged wavy text-decoration properties on unlocated anchors with
  a dashed bottom border, retaining the warning color and explanation.

## Findings retained deliberately

The custom source-available license is not recognized as a standard license by
GitHub's classifier. No license terms are changed merely to improve a scorecard.
The declarative-settings warning remains the documented minimum-app compatibility
choice: the bespoke asynchronous settings dashboard supports Obsidian 1.7.2,
while settings definitions require a newer API. See CODE-STANDARDS.md.
Vault enumeration and clipboard access are capabilities of the existing review
workflow; informational capability disclosures are not removed or hidden.

and official typed report lint pass with zero errors; the documented settings
